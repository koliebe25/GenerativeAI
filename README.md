## 설치된 도구

| 도구 | 설명 | 가이드 |
|---|---|---|
| [Open Generative AI](https://github.com/Anil-matcha/Open-Generative-AI) (`open-generative-ai/`) | 이미지·영상·음악·립싱크 AI 모델 400여 개를 한 화면에서 쓰는 오픈소스 AI 스튜디오 | [설치 가이드](docs/open-generative-ai/README.md) |

소스코드로 바로 설치하기:

```bash
git clone --recurse-submodules https://github.com/koliebe25/GenerativeAI.git
cd GenerativeAI
bash scripts/setup-open-generative-ai.sh
```
