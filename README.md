# GenerativeAI
생성형 AI 관련

## 설치된 도구

| 도구 | 설명 | 가이드 |
|---|---|---|
| [Open Generative AI](https://github.com/Anil-matcha/Open-Generative-AI) 한국어 수업용 버전 (`open-generative-ai/`) | 이미지·영상·음악·립싱크 AI 모델 400여 개를 한 화면에서 쓰는 오픈소스 AI 스튜디오. 한국어 화면 + 수업 모드(강사 키 + 수업 코드) | [강사용 가이드](docs/open-generative-ai/README.md) · [수강생 안내문](docs/open-generative-ai/student-guide.md) |

수업용 사이트: https://open-generative-ai-ko.vercel.app

내 PC에서 실행하기:

```bash
git clone https://github.com/koliebe25/GenerativeAI.git
cd GenerativeAI
bash scripts/setup-open-generative-ai.sh
```
